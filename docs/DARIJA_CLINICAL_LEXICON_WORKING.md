# Darija Clinical Lexicon — Working Native Review Batch 01

Status: **WORKING / NON-RUNTIME / NOT CLINICALLY CERTIFIED**

Date: 2026-08-14
Locale target: Moroccan Darija (`ar-MA`)
Source: interactive native-speaker review session.

## Governance boundary

This document records language candidates accepted during native-language review. It is **not** a clinical approval, safety-corpus approval, release certification, or authorization to add these phrases to runtime triage/classification logic.

Before any runtime use, each candidate requires the applicable clinical-safety review, positive/negative test design, false-positive analysis, and existing fail-closed release gates.

Naturalness rankings below reflect the native review session only. They are not medical-severity rankings.

## Batch 01

### 01 — Presyncope / feeling about to faint
French gloss: « Je vais m’évanouir / je sens que je vais perdre connaissance. »

Accepted:
- `حاس براسي غادي نطيح`
- `حاس براسي غادي نفقد الوعي`
- `غادي يغمى عليا`

Note: all accepted; no strict naturalness ranking recorded. The first two were preferred over the third, while the third was explicitly considered valid.

### 02 — Trembling / tremor
French gloss: « Je tremble / j’ai des tremblements. »

Accepted:
- `كنترعد`
- `كنرجف`
- `كنرعش`
- `كنحس براسي كنترعد`

Note: all four explicitly accepted as correct.

### 03 — Dizziness / head spinning
French gloss: « J’ai des vertiges / la tête tourne. »

Accepted naturalness order:
1. `كتدور بيا الدنيا`
2. `راسي كيدور بيا`
3. `حاس براسي دايخ`
4. `دايخ`

### 04 — Blurred vision
French gloss: « Je vois flou / ma vision est brouillée. »

Accepted:

- `النظر مضبب عندي`
- `ما بقيتش كنشوف مزيان`
- `كنشوف كلشي مضبب`

Rejected lexical form for this session:
- `مغبش`

Native correction: use `مضبب` instead of `مغبش` in these formulations.

### 14 — Abdominal pain / gastric burning

### 19 — Severe fatigue / exhaustion
French gloss: « Je suis très fatigué / épuisé. »

Accepted:
- `عييت بزاف`
- `حاس براسي عيان بزاف`
- `مرخي بزاف`
- `ماعندي جهد`
- `حاس براسي مسخسخ`
- `حاس ب راسي مطحطح`

Note: `مسخسخ` and `مطحطح` were supplied as stronger exhaustion expressions. Their exact intensity boundary remains contextual and is not clinically classified here.

### 20 — Cold / shivering from cold
French gloss: « J’ai froid / je frissonne. »

Accepted:
- `فيا البرد`
- `فيا الموت ديال البرد`
- `كنترعد بالبرد`
- `كنغزل بالبرد`

Important false-positive boundary:
- `فيا الموت ديال البرد` is an intense/hyperbolic cold expression. The token `الموت` must **not** by itself be interpreted as death, suicidality, or a literal life-threatening statement.

- `الكحبة`

Accepted formulations:
- `كنكح بزاف`
- `فيا الكحة بزاف`
- `شداتني الكحة`
- `الكحة ما بغاتش تحبس`

### 22 — Sore / irritated throat
French gloss: « J’ai mal à la gorge. »

Accepted:
- `حلقي كايدرني`
- `حاس بحلقي كايدرني`
- `حلقي محروق`

Semantic note: `حلقي محروق` is closer to burning/irritation than a generic pain label and should remain distinguishable.

### 24 — Back / kidney-area pain
French gloss: « J’ai mal au dos / aux reins. »

Accepted:
- `ظهري كايدرني`
- `كلاوي كايدروني`

Boundary: these two expressions should not automatically be treated as anatomically or diagnostically equivalent.

### 25 — Joint / knee pain or heaviness
French gloss: « J’ai mal aux articulations / aux genoux. »

Accepted:
- `مفاصلي كايدروني`
- `ركابي كايدروني`
- `ركابي تقالو عليا`

Semantic note: `ركابي تقالو عليا` expresses heaviness and should remain distinguishable from explicit pain.

### 26 — Heavy / weak legs

Other proposed formulations were not retained.

## Review rules for the next batch

1. Preserve native naturalness rankings where explicitly supplied.
2. Keep symptom, severity, anatomical location, and figurative language separate.
3. Record rejected and ambiguous candidates because false positives matter as much as positive recall.
4. Add Arabizi variants only after separate native review; do not transliterate mechanically.
5. Do not promote any item into runtime triage from this working document alone.
6. Before runtime promotion, build positive, negative, contextual, and hyperbole regression cases for each promoted concept.

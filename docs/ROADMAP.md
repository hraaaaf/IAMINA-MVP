# IAMINA — ROADMAP UNIQUE WEB V2 — 15 octobre 2026
> **PRIORITÉ CANONIQUE.** Ce bloc est le seul plan prospectif IAMINA. Les 29 décisions D1–D29 restent approuvées comme décisions produit, **pas comme livraisons** ; leur numéro n'impose pas l'ordre d'exécution. **Chacune sera réexaminée individuellement** avant son implémentation Web (conserver / ajuster / abandonner / différer) selon faisabilité, dépendances, sécurité et intérêt patient ; pas de validation tacite du code hérité. Les anciennes étapes V1, pages de handover, tableaux P5 et entrées de journal ci-dessous servent désormais d'**archives et preuves**, sans concurrence pour la priorité future. Travaux uniquement **Web / PWA**, pas de chantier natif iOS/Android. Pas de déploiement Vercel ni de données patients réelles sans décisions humaines distinctes.
## Cible technique Web — cadrage et non déploiement
- **Projet Vercel frontend séparé :** Flutter Web/PWA, responsive téléphone/tablette/desktop, clavier, AR/RTL, vrai navigateur. Aucun secret serveur embarqué.
- **Projet Vercel backend séparé :** Django + django-ninja, APIs, identité et consentements, règles cliniques déterministes, connecteurs contrôlés. Contrôler contraintes serverless, tâches de fond, traitements longs et limites d'exécution.
- **DB PostgreSQL : Neon managé, connecté au seul projet backend Vercel.** Le moteur PostgreSQL n'est pas hébergé dans les fonctions Vercel. Séparer les données/dev/preview/patient, migrations, secrets, backups et restaurations. Projet Neon IAMINA historique déjà identifié, réutilisation à vérifier avant tout changement.
- **Frontière patient :** HTTPS, authentification/autorisation object-level, isolation patients, cookies/CSRF/CORS cohérents, gestion des clés, conservation Web chiffrée et synchronisation A-WEB-01/A-WEB-02 à définir. La nouvelle topologie ne remplace pas sans examen la doctrine local-first.
- **Gates :** aucune exposition identifiable ni LLM tiers, ni distribution/déploiement Vercel sans preuves sécurité, résidence/transferts applicables, consentement, revue clinique et autorisation explicite du propriétaire.

# IAMINA local launcher

`IAMINA.py` is the only canonical host launcher.

- Windows: `python IAMINA.py`
- macOS: `python3 IAMINA.py`
- backend: `http://127.0.0.1:8008`
- frontend: `http://localhost:8009`

See `docs/DEPENDENCIES.md` for prerequisites and `docs/assessments/2026-08-19-single-cross-platform-launcher-audit.md` for the audit and certification contract.

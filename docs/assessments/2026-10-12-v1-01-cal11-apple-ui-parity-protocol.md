## CAL-11 Chrome — Service Worker causal A/B verification attempt

- At commit [`695baaeaca8ccc4b172ac3de9d022a180094bafc`](https://github.com/hraaaaf/IAMINA-MVP/commit/695baaeaca8ccc4b172ac3de9d022a180094bafc), exact-head Chrome run [#38304709556](https://github.com/hraaaaf/IAMINA-MVP/actions/runs/38304709556) and CI [#38304709429](https://github.com/hraaaaf/IAMINA-MVP/actions/runs/38304709429) were **19/19 SUCCESS**, but **all 18 Chrome cases recorded** the *same JavaScript pageerror*: `startup`, `TypeError: Cannot read properties of undefined (reading 'update')`, stack `http://127.0.0.1:7367/flutter_bootstrap.js:122:26`. Activation of Flutter semantics and observation phases did not originate this exception.
- The **tracked product bootstrap** `frontend/web/flutter_bootstrap.js` explicitly invokes `registration.update()` 3 seconds after `navigator.serviceWorker.register(...).then((registration) => ...)`, while our previous test created all Playwright contexts with `serviceWorkers: 'block'`. **Working hypothesis**: interception prevents a valid `ServiceWorkerRegistration` value even though the promise resolves. Both BEFORE and AFTER had the same startup error. Do not treat this as fully proven until allowed mode produces no error.
- **QA-only A/B remediation proposed/implemented for next HEAD** in `tools/v1_01_cal11_nutrition_browser_capture.cjs`: switch to `serviceWorkers: 'allow'`, require a real service-worker registration in every isolated locale/viewport context, and **FAIL immediately on any `pageerror`**; keep all 18 real PNGs, source-backed text checks, same 100 g fixture, and PNG/diff/dimensions checks. Each Playwright browser context has separate cache/SW storage, preventing source contamination between BEFORE/AFTER. The patient product bootstrap and all production code remain untouched.
- **Validation gate:** wait for new exact-HEAD Chrome + CI and inspect logs, `pageErrors: []` and `serviceWorkerRegistry.count >= 1` across 18 observations. If not, diagnose and correct the harness; do not call it fixed.
